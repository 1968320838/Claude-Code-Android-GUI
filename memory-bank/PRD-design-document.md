## 1. 文档概述

### 1.1 目的

本文档定义 ClaudeBox 产品的功能需求、非功能需求、UI/UX 规范及验收标准，作为产品设计、开发、测试的基准。

### 1.2 范围

本文档涵盖 ClaudeBox Android 客户端的所有核心功能需求，包括 Termux 连接管理、会话管理、终端模拟器、文件浏览器、Claude Code 交互、设置模块。

### 1.3 术语说明

| 术语 | 定义 |
|------|------|
| Termux | Android 上的 Linux 环境模拟器 |
| Claude Code | Anthropic 提供的 AI 编程辅助 CLI 工具 |
| PTY | Pseudo-Terminal，伪终端，用于 SSH 实时通信 |
| MVVM | Model-View-ViewModel，架构模式 |

## 2. 产品介绍

### 2.1 产品背景

ClaudeBox 是一款 Android 图形界面客户端，通过 SSH 连接 Termux，为运行在 Termux 环境中的 Claude Code CLI 提供移动端界面。

当前市场缺乏针对 Claude Code 的移动端图形化客户端，而移动设备（平板、大屏手机）的性能已足以支持轻量级编程工作。

### 2.2 产品目标

- 让开发者可以在 Android 设备上使用 Claude Code 进行 AI 编程辅助
- 提供流畅的移动端编程体验
- 支持多种使用场景（通勤、外出、应急）

### 2.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 便携性 | 随时随地使用 Claude Code |
| 移动优化 | 触控友好，界面适配手机/平板 |
| 完整功能 | 通过 SSH 保留 CLI 的全部功能 |
| 快速响应 | 本地连接低延迟 |

### 2.4 用户画像

| 用户类型 | 场景 | 核心需求 |
|----------|------|----------|
| 移动开发者 | 外出时用平板查看代码 | 快速连接，核心功能可用 |
| 学生开发者 | 随时学习编程 | 便携性强，操作简单 |
| 应急开发者 | 紧急问题处理 | 连接快，能快速定位问题 |

## 3. 功能需求

### 3.1 连接管理模块（F1）

**优先级：P0（必须）**

#### F1.1 SSH 连接

- 通过 SSH 协议连接 Termux
- 支持密码认证和密钥认证
- 维护持久连接，支持 PTY（伪终端）
- 连接建立时间 < 5秒

#### F1.2 连接配置

- 配置项：主机地址、端口号、用户名、认证方式
- 支持密码和私钥文件两种认证方式
- 配置加密存储，不明文保存密码

#### F1.3 连接状态管理

- 实时显示连接状态（已连接/连接中/断开）
- 连接断开时显示错误原因
- 支持手动断开连接

#### F1.4 自动重连（P1）

- 网络波动后自动尝试重连
- 最多重试 3 次，间隔 2 秒
- 重连失败后提示用户

**验收条件**：
- [ ] 能使用密码认证成功连接 Termux
- [ ] 能使用密钥认证成功连接 Termux
- [ ] 连接断开后显示正确状态
- [ ] 手动重连功能正常

---

### 3.2 会话管理模块（F2）

**优先级：P0（必须）**

#### F2.1 会话列表

- 展示所有 Claude Code 会话
- 显示每个会话的最后活跃时间
- 支持按时间排序

#### F2.2 创建会话

- 点击即创建新会话
- 新会话自动连接到 Claude Code CLI

#### F2.3 切换会话

- 快速在不同会话间切换
- 切换后保留终端滚动位置

#### F2.4 删除会话（P1）

- 左滑或长按删除会话
- 删除前二次确认
- 删除后清空会话相关数据

#### F2.5 会话持久化（P1）

- 退出会话时保存状态
- 下次打开时恢复会话

**验收条件**：
- [ ] 能创建新会话
- [ ] 能切换会话
- [ ] 能删除会话
- [ ] 会话列表正确显示

---

### 3.3 终端模拟器模块（F3）

**优先级：P0（必须）**

#### F3.1 终端显示

- 全屏显示 Claude Code CLI 输出
- 支持滚动浏览历史内容
- 触控滚动流畅，无卡顿

#### F3.2 ANSI 颜色支持

- 正确解析并显示 ANSI 转义序列
- 支持 16 色和 256 色模式

#### F3.3 文本选择

- 长按选中文本
- 支持复制选中文本
- 选中文本后显示操作菜单（复制）

#### F3.4 键盘输入

- 调用系统软键盘
- 支持常用快捷键（Ctrl+C, Ctrl+D 等）

#### F3.5 多会话 Tab（P2）

- 支持在一个界面打开多个终端 Tab
- Tab 切换流畅

#### F3.6 语法高亮（P1）

- 代码块语法高亮显示
- 使用 Highlight.js 实现

**验收条件**：
- [ ] 终端输出正确显示
- [ ] ANSI 颜色正确渲染
- [ ] 滚动操作流畅
- [ ] 长按文本可复制

---

### 3.5 Claude Code 交互模块（F5）

**优先级：P0（必须）**

#### F5.1 发送消息

- 底部输入框发送消息到 Claude Code

- 发送后清空输入框

#### F5.2 实时响应流

- 流式显示 Claude Code 输出
- 响应内容实时更新
- 支持中断正在生成的响应（P1）

#### F5.3 Markdown 渲染

- AI 返回的 Markdown 内容正确渲染
- 支持标题、列表、链接等

#### F5.4 代码块高亮

- 代码块识别并高亮
- 支持代码块复制

#### F5.5 消息操作（P1）

- 复制消息内容
- 重发上一条消息

**验收条件**：
- [ ] 能发送消息并收到响应
- [ ] 响应流式显示
- [ ] Markdown 正确渲染
- [ ] 代码块正确高亮

## 4. UI/UX 需求

### 4.1 页面结构

```
MainActivity
└── BottomNavigation
    ├── 会话 (ChatFragment)
    ├── 终端 (TerminalFragment)
    ├── 文件 (FilesFragment)
    └── 设置 (SettingsFragment)
```

**说明**：
- BottomNavigation 为底部导航栏
- ViewPager2 支持多会话 Tab 切换
- 每个 Fragment 对应一个功能模块

### 4.2 视觉规范

| 元素 | 规范 |
|------|------|
| 设计语言 | Material Design 3 |
| 主色 | #6750A4 (Material You 紫色) |
| 深色背景 | #1C1B1F |
| 浅色背景 | #FFFBFE |
| 代码背景 | #2D2D2D |
| 字体 | 系统默认等宽字体 |

### 4.3 交互规范

- 触控目标最小 48dp
- 按钮点击反馈 200ms 内
- 页面切换动画 300ms
- 列表滚动帧率 60fps

## 5. 非功能需求

### 5.1 性能指标

| 指标 | 要求 |
|------|------|
| 冷启动时间 | < 3 秒 |
| 终端输入延迟 | < 100ms |
| 内存占用 | < 200MB |
| SSH 连接建立 | < 5 秒 |

### 5.2 兼容性

| 项目 | 要求 |
|------|------|
| 最低 Android 版本 | Android 7.0 (API 24) |
| 目标 Android 版本 | Android 14 (API 34) |
| Termux 兼容性 | 支持 openssh |

### 5.3 安全

- SSH 密钥加密存储（Android Keystore）
- 不明文保存密码
- 连接信息不写入日志

### 5.4 可靠性

- 自动重连机制
- 网络异常处理
- 崩溃恢复

## 6. 验收标准

### 6.1 功能验收

| 模块 | 验收项 | 通过标准 |
|------|--------|----------|
| 连接 | SSH 密码认证 | 能成功连接 Termux |
| 连接 | SSH 密钥认证 | 能成功连接 Termux |
| 会话 | 创建/切换/删除 | 功能正常 |
| 终端 | 显示/滚动/选择 | 流畅无卡顿 |
| 聊天 | 发送/接收消息 | 正常交互 |
| 设置 | 配置保存/加载 | 正确持久化 |

### 6.2 测试场景

**场景 1：首次连接**
1. 打开应用
2. 输入 SSH 配置
3. 点击连接
4. 预期：连接成功，显示终端

**场景 2：发送消息**
1. 连接成功后
2. 在输入框输入 "Hello"
3. 点击发送
4. 预期：收到 Claude Code 响应

**场景 3：切换会话**
1. 在会话列表
2. 点击另一个会话
3. 预期：切换成功，终端内容更新

**场景 4：主题切换**
1. 进入设置
2. 切换到浅色模式
3. 预期：界面主题变更
